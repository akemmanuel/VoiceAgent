# Extension icons

`icon.svg` is the bold Waveform icon rendered from `@phosphor-icons/react` 2.1.10 in `#226456`. The PNG files are transparent raster versions at 16, 32, 48, and 128 pixels, created with ImageMagick. These are starter icons, not a custom logo.
